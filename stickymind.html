StickyMind.

TYPE Web Application
TECHNOLOGIES Python · Flask · SQLite

Visit live website ↗ GitHub source ↗
01 / THE IDEA

Your thoughts,
in one place.

StickyMind is a productivity web application designed to help users organize their everyday thoughts, notes, and reminders.

The idea was to create a simple digital space where important information can be stored and accessed without unnecessary complexity.

02 / DEVELOPMENT

Built to learn.
Made to work.

I built StickyMind using Python and Flask for the backend, with SQLite for data storage.

Working on this project helped me understand backend development, database operations, application structure, and connecting a frontend interface with backend APIs.
