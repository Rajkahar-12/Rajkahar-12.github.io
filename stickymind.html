StickyMind.

A productivity application designed to help users organize their thoughts, manage tasks and keep track of the things that matter.

Python Flask SQLite Web Application
ABOUT THE PROJECT

A simpler way to stay organized.

StickyMind is a productivity-focused web application built to make organizing everyday tasks and ideas easier.

The project uses Python and Flask for its backend, with SQLite handling data storage. It gave me an opportunity to understand how a web application works beyond its interface.

Building StickyMind helped me explore backend logic, database operations, application structure and the process of turning an idea into a functional product.
