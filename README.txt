HOW TO USE
1. Extract this folder.
2. Open your GitHub repository: Rajkahar-12/Rajkahar-12.github.io
3. Replace every matching file with the files from this folder.
4. Keep your existing assets/ folder exactly as it is.
   Required images:
   - assets/projects/stickymind.png
   - assets/projects/rashai.png
   - assets/projects/slidewala.png
5. Commit to the default branch.
6. Wait for GitHub Pages to deploy, then refresh https://rajkahar.is-a.dev/

IMPORTANT — CUSTOM DOMAIN
- The custom domain rajkahar.is-a.dev should point to THIS portfolio repository.
- The live project links point to the separate Render apps:
  - https://stickymind.onrender.com
  - https://rashai.onrender.com
  - https://slidewala.onrender.com
