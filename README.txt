RAJ KAHAR PORTFOLIO REDESIGN

Files:
- index.html: redesigned homepage
- portfolio-redesign.css: new homepage design layer

How to install:
1. Download and extract this ZIP.
2. Open your GitHub repository: Rajkahar-12/Rajkahar-12.github.io
3. Upload/replace index.html in the repository root.
4. Upload portfolio-redesign.css to the same root folder.
5. Commit the changes to the main branch.
6. Wait for GitHub Pages to redeploy, then refresh your portfolio.

Important:
- Keep your existing style.css and script.js.
- Keep the assets/ folder and existing project screenshots.
- Keep about.html, work.html, stickymind.html, rashai.html and slidewala.html.
- The redesigned homepage links to the existing project detail pages.
- No backend or new framework is required.
