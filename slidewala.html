01 / THE IDEA

From an idea
to a presentation.

SlideWala is an AI-powered tool designed to simplify presentation creation.

Users enter a topic and generate structured presentation content with the help of AI, reducing the effort required to start building a presentation from scratch.

02 / THE EXPERIENCE

Presentations
your way.

SlideWala explores different presentation lengths, audiences, writing tones and visual themes.

These options give users more control over how their generated presentations are structured and presented.

03 / THE BUILD

artificial intelligence.

I built SlideWala using Python and Flask, integrating AI APIs to generate presentation content.

This project helped me explore backend development, API integration, presentation generation and connecting multiple technologies into one working product.
