ABOUT THE PROJECT

From an idea to a presentation.

SlideWala is an AI-powered web application designed to help users generate presentation content from a topic.

Users can customize their presentation preferences, including the number of slides, audience, tone and visual theme.

The application uses Python and Flask on the backend, AI APIs for content generation and python-pptx to create downloadable PowerPoint presentations.

Working on SlideWala helped me explore API integration, backend development, file generation and building a more complete web application.
