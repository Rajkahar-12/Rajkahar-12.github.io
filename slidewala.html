What it does.

TYPEAI Presentation Generator
TECH STACKPython · Flask · AI APIs · python-pptx
ROLEDesign & Development
LIVE PROJECTslidewala.onrender.com ↗

SlideWala helps users turn an idea or topic into a presentation. It generates structured slide content so users can spend less time starting from a blank page and more time refining their message.

Built with Python and Flask, the project integrates AI APIs for content generation and python-pptx for creating downloadable PowerPoint files. It helped me explore API integration and document generation.
